# Security

Report a suspected launcher vulnerability privately through
[GitHub private vulnerability reporting](https://github.com/extelonlabs/warlords-launcher/security/advisories/new).
If that feature is unavailable, ask a maintainer to enable a private reporting
channel without posting exploit details, credentials or player data publicly.

Include the launcher version, affected file/function, prerequisites, impact and
minimal reproduction using your own disposable files. Do not probe other
players, public servers or services without their owners' permission. Never
include real credentials or personal data in a report.

The latest published launcher is the supported testing version; there is no
guaranteed response time or security certification. The executable and catalog
are currently unsigned. Hashes are checked against the catalog, so compromise
of the distribution account/catalog remains a trust boundary. Open publication
does not eliminate implementation defects or establish binary reproducibility.
Changing the selected catalog grants its publisher update authority. The app
does not require every custom catalog to include expiry and has no independent
minimum-release floor. These limits also apply to privately distributed builds.
