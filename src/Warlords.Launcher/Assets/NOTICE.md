# Warlords branding

The PNG is a byte-for-byte copy of the existing Warlords project crest used by
the loading screen. The Windows icon contains scaled frames of the same complete
artwork; it does not redraw or crop the crest.

The artwork retains its existing rights. The MIT license for the original
launcher code does not relicense the Warlords name or logo. This notice makes no
new authorship, ownership or separate license grant for the branding artwork.
